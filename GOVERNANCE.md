# Governance

Tribrach is a fully open-source project under the Apache-2.0 licence. There is
no paid edition: the core, every instrument and every pack are open.

## Roles

- **Maintainers** review and merge changes, cut releases and decide the
  roadmap. They are the owners of the `tribrach-dev` GitHub organisation.
- **Contributors** are anyone who opens an issue or a signed-off pull request.

## Decisions

Maintainers aim for consensus in issues or pull requests. Where consensus
doesn't come, the lead maintainer decides and records why. Changes to the
shared formats (manifest, vectors, stamps, claims) need an issue describing the
change and its compatibility impact before a pull request.

## Becoming a maintainer

Contributors with a sustained record of good changes and reviews can be
invited by the existing maintainers.

## The name

"Tribrach" and the project logo identify this project. Forks are welcome but
should use a different name. A fuller trademark policy will follow before the
first public release.

## Future home

If the project grows beyond a few maintainers, it may move to a neutral
foundation. That would change ownership of the organisation, not the licence.
